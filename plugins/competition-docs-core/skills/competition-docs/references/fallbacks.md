# 自动替代与失败处理

用户选择：自动替代；确实不行先跳过，跑完可执行流程后集中说明。此设置适用于工具不可用和产物生成失败，不构成运行项目、安装字体、付费、公开发布或越权访问的授权。

- 瞬时只读网络错误最多重试一次；权限/账户/无工具不重复相同调用。每节点最多尝试主路线和两条已存在且可用的替代路线，随后 skipped。
- 不下载未核实脚本、不自动装服务、不修改上游技能实现来“修复依赖”。需要账户或审批时标 waiting；其他独立节点继续，末尾集中列出动作。
- Zotero 导入失败：直接读取工作副本可继续内容分析，但记录导入未完成、引用元数据缺失，不声称遵循了统一入库。写入超时先查状态，禁止盲重放。
- GitHub 不可用：用已有本地副本/其他只读读取，保留 commit；只有 README 时局限于 README 的陈述。
- Exa 不可用：其他已连接搜索与抓取；无外网则仅用现有材料，将新增外部事实标未核实/缺失。
- Canva 不可用/导出受限：本地模板、已有参考、或本地生成预览；记录未使用 Canva，禁止冒充模板来自 Canva。
- PPT 主路线失败：换另一条可用生成路线。HTML/PDF 可以作为中间稿，但 PPTX 请求仍为未完成。
- DOCX/PDF 渲染失败：尝试已有兼容渲染器；仍失败输出未验证草稿，不能称最终合规成品。
- 输入文件无法读取：记录具体文件、影响范围，跳过依赖该来源的事实；其他来源继续。必要的用户选择不可被脚本 allow-partial 绕过。

状态例：source:paper skipped → downstream content done --allow-partial → docx 草稿；qa failed；report 列入缺少论文证据。若没有任何可用素材，只能完成要求分析/缺口报告，不伪造正文。

恢复时保留问题历史；补齐材料后重新读取、刷新事实台账、使受影响节点 stale 并重做检查。不能通过把 skipped 改名成 done 掩盖失败。
