# Canva 与 PPT 路由

## Canva 两种角色
先读取当前 Canva 技能及真实工具 schema，区分：账户内设计搜索、可用的模板库搜索、品牌模板 autofill、候选生成和导出。`search-designs` 不等于可检索整个公共模板库；不能承诺任意 Canva 模板都可导出或免费编辑。没有品牌套件不应让普通竞赛 PPT 停住，改用普通设计或外部风格参考。

1. 风格参考：寻找账户可访问设计或生成候选，展示必要预览；记录设计 id/URL、配色、字体、布局语法与使用条件。参考设计不是项目事实来源。
2. 原生模板：仅当当前工具和账户支持 PPTX 导出时使用；下载后确认 ZIP/OOXML 合法、页数、文字和主要对象是否可编辑，检查母版、字体和图片。导出图像不等于可编辑模板，不把整页截图当可编辑 PPTX。

用户已提供明确设计或模板时复用；需要选择时集中展示少量有区别候选并确认一次。付费/受限内容跳过而不购买，不收集用户密码。获取模板失败则采用本地风格预览，最终说明替代；不要在公共 Canva 上传未获准公开的项目源码和材料。

## 自动路线
- 已取得原生 PPTX 模板+新内容 → ppt-master Edit Native PPTX，保留模板设计；遵循自身 routing，不把 raw PPTX 误当内部模板 workspace。
- 无模板，主要目标可编辑 PPTX → ppt-master Generate PPTX；真正请求复用模板工作区时才用 Create Template。
- 明确需要 HTML 展示/动画或选中的视觉方向适合 HTML → slides，最终需要 PPTX 时再运行 html-to-pptx。
- 某路线不可用 → 有限次替代；保留可用中间稿，缺 PPTX 就报 PPTX 未完成。

用一句中文报告选择原因。按演讲时长或阅读用途确定密度；未知且影响设计时询问。以官方画幅、页数限制和模板为先；slides 固定 16:9，如竞赛强制其他画幅，转 ppt-master，不能悄悄违反要求。

## 调用纪律
ppt-master 的 SKILL_DIR 必须是已发现的真实绝对目录，先运行 attribution_guard.py，非零则停止该路线，禁止修补或绕过。再按 routing 只加载一个运行入口。复制后的技能保持原始文件和署名不变。

slides 执行自己的固定舞台、字体、presenter runtime 和视觉检查；已有用户选定 Canva 方向时把它作为明确参考，不让用户无意义重选三次。无法用既有确认满足工具关口时，按实际工具要求等待，不伪造授权。

HTML 转换读取本机字体与 audit 配置；需要安装字体时必须有用户授权。没有配置可按总控默认要求建议 triage，但不能自行写成用户同意安装字体。使用实际 convert.py 的绝对路径，修复 audited.html 副本，保留原 HTML。首轮全量，后续 --only-slides 仅适用于真正局部修改；全局 CSS/字体变更全量重跑。

没有 PPT 渲染器时尝试其他已有渲染方案，不能为了验证而擅自安装大型软件。若仍不能检查，保存未审计 PPTX 草稿并标 unverified，继续其他文件；不得当作通过验收成品。收尾遵循用户“失败跳过，末尾集中报告”的选择，不反复打断其余工作。

## 视觉验证
DOCX/PDF/PPTX 各自渲染并实际检查所有页；HTML 在桌面和手机视口保持完整画幅，无溢出与遮挡。HTML → PPTX 对比源画面和转换画面，记录字体、文字可编辑性、公式图表、装饰栅格化和动画损失。能用原生文字/形状的内容保持可编辑，复杂装饰才栅格兜底；不承诺像素级一致。
